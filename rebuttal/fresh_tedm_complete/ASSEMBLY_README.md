This directory assembles five completed independent training seeds. No model was fitted, scored, selected or recalibrated by the merge. Every source protocol is identical after removing only its seeds field. The original all-five-seed registration is preserved in global_registered_protocol.json. Each seed result is byte-identical to its source and retains the SHA256 of seed_S/execution_protocol.json. The top-level protocol adds explicit worker provenance, so its hash intentionally differs. Summary means and sample SD use exactly seeds 1,7,19,37,73. With the default compact option, checkpoint and full-scenario hashes refer to retained source-worker artifacts; they are not fabricated local files. Per-origin paired losses are included for downstream temporal inference. Worker numerical-audit snapshots may contain process-wide counters beyond the selected completed seed; result.json is the completed-run record.
