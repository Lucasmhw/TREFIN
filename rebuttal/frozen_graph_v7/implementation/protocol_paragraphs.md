The proposed text below describes the registered protocol only. It contains no outcome claims and should be paired with the completed results before inclusion in the manuscript or replies.

**Retained-channel graph-evolution control.** We compare Full with a fully retrained FrozenGraph control that sets $A_{t+h}=A_t$ at every future step. Both models retain typed concept propagation, the decoder's $AC$ features, its graph-dependent precision, the same market-state inputs, and the same probabilistic decoder. FrozenGraph therefore isolates learned graph evolution from access to a graph channel. Its graph-target loss coefficient is zero because the fixed path has no trainable dependence. Its gain penalty uses the bound for the actual augmented transition $(C,A)\mapsto(F_C(C,A),A)$, namely $\bigl[\begin{smallmatrix}m_{CC}&m_{CA}\\0&1\end{smallmatrix}\bigr]$, with radius $\max(m_{CC},1)$; all other loss coefficients remain those of the corresponding candidate. The unused proposal encoders are retained only to preserve initialization order and receive no gradients.

**Matched validation selection.** On each chronological fold, we select configurations separately for Full and FrozenGraph using seed 1 and the same four nominal candidate slots: the original configuration; graph refresh 0.02; residual scale 0.05 with graph refresh 0.10; and concept/graph supervision coefficients 0.10/0.02. FrozenGraph's graph coefficient remains zero. Its refresh-only slot is identical to its base configuration, so that duplicate is recorded without reallocating its budget. Each distinct candidate uses a 20-epoch ceiling, patience 6, batch size 64, and the original optimizer and learning rate. Checkpoints are selected by validation ES using 64 scenarios; the same validation-only positive mean scalar $\rho\in[0.05,1]$ is then fitted, and candidates are ranked by calibrated validation ES. The six fold/model choices are fixed before any held-out evaluation. The selected seed-1 checkpoints are reused, and the four remaining seeds are fitted from initialization under the selected configurations. This yields five-seed comparisons on all three folds, with 256 test scenarios per origin.

**Metrics and scope.** We report the complete point, distributional and state metric suites for both models, including five-seed sample standard deviations. Paired comparisons average losses over training seeds at each chronological test origin before temporal resampling. Graph-state errors and support IoU answer how closely a forecast follows the measured graph targets; Full versus FrozenGraph tests whether allowing the retained graph channel to evolve improves downstream forecasts under this matched retraining protocol. These are distinct questions, and their outcomes should be reported separately.
