# Model-to-code consistency map

## Three parameter classes

| Class | Examples | How obtained | Backpropagated? |
|---|---|---|---:|
| Prior-fixed measurement choices | factor names, concept scales, graph window, soft-gate definition | preregistered or selected only inside training/validation | No |
| Rolling statistical estimates | factor intercept/beta, residual covariance, precision matrix, partial correlations, current concepts and market state | beta/concepts are recomputed at every origin; the residual graph is refitted at the configured causal cadence and otherwise carried forward | No |
| Neural parameters | dynamics MLPs, graph embeddings, state modulation heads, lead embeddings, decoder heads | AdamW on the total training objective | Yes |
| Validation-calibrated decision parameter | positive predictable-signal gate `rho` | global minimum of a bounded one-dimensional convex validation Energy Score after checkpoint selection | No |

This distinction is enforced by the data/model boundary. `build_research_dataset` computes
all rolling statistical estimates in NumPy/scikit-learn before tensors enter `FCONCORD`.

## Equation and implementation map

| Mathematical object | Implementation | Important invariant |
|---|---|---|
| Exponential lag weights | `concepts.exponential_lag_weights` | positive, current-to-oldest, sum to one |
| Rolling ridge factor exposure | `concepts.fit_weighted_ridge_factor_model` | intercept unpenalized; no future observations |
| Momentum, semivariance, jump, illiquidity, order flow | `concepts.compute_asset_concepts` | fixed coordinate order |
| Factor residual | `_StateBuilder.build` in `data/dataset.py` | one origin-specific beta is fixed across its graph window |
| Standardized residual matrix | `_StateBuilder.build` | per-asset centering/scaling before graph estimation |
| Graphical Lasso and partial correlation | `graph.estimate_partial_correlation` | positive precision; symmetric zero-diagonal partial correlation; convergence/retry/fallback audited |
| Smooth signed graph | `graph.smooth_signed_graph` | continuous soft gate; signed edges retained |
| Three market concepts | `_StateBuilder.build` | log market variance, mean absolute residual partial correlation, mean log illiquidity |
| Signed/unsigned typed Laplacian | `model.typed_graph_operator` | directional concepts use signed Laplacian; magnitudes use unsigned Laplacian |
| Parallel concept/graph update | `FCONCORD._step` | both next states read only the old pair `(C_h,A_h)` |
| State projection | `clamp` and `project_graph` | concept box; symmetric zero-diagonal Frobenius graph ball |
| Train-only return scale | `build_research_dataset` metadata and `FCONCORD.return_scale` | per-asset robust scale is fitted before validation/test and travels with the checkpoint model |
| Joint precision and correlation | `FCONCORD._decode_state` | precision is strictly positive definite |
| Unit-variance Student-t shock | `FCONCORD._sample_distribution` | common chi-square scale across assets per horizon |
| Mean-centering correction | `FCONCORD._sample_distribution` | decoder `mu` is the conditional mean |
| Predictable-signal calibration | `calibration.calibrate_predictable_signal` and `FCONCORD.signal_shrinkage` | validation only; `0.05 <= rho <= 1`; scenario differences and the Energy Score pairwise term are invariant |
| Energy score | `losses.energy_score` | multivariate strictly proper score in population |
| Auxiliary concept/graph losses | `losses.total_loss` | future states are labels, never inference inputs |
| Risk monotonicity | risk coordinates are zeroed in unconstrained scale heads; bounded softmax risk channel | downside scale has nonnegative named-risk slopes at fixed graph/state by construction |
| Small-gain optimization proxy | `FCONCORD.gain_proxy` | logged separately from a formal theorem certificate |

## Factor beta lifecycle

At forecast origin `t`:

1. slice returns and observed factor returns over `[t-W_g+1,t]`;
2. solve the exponentially weighted ridge problem;
3. append the resulting `beta[t,i,:]` to the current asset concept vector;
4. compute every historical residual in that graph window with the same origin-specific beta;
5. on a registered graph-refit origin, estimate the residual graph; otherwise carry the latest past graph forward without future interpolation;
6. during offline training only, repeat the same causal operator at `t+h` to obtain future concept labels;
7. during inference, never execute the future operator: future beta coordinates must be generated by concept dynamics.

## Strict bottleneck software rule

After `build_research_dataset` produces `c0`, `a0` and `s0`, `FCONCORD.forward` accepts only
those tensors. Prices, volumes, raw returns and factor matrices are absent from the model
signature, so no raw-history skip connection can be introduced accidentally.

## Predictable-signal gate lifecycle

For the calibrated configuration, the neural network is trained with `rho=1`. Validation
Energy Score selects `best.pt`; no test array has been loaded. The selected checkpoint then
produces validation means `mu` and scenarios `mu + epsilon^(s)`. The calibration module
minimizes

`mean_{s,t,h} ||epsilon^(s)_{t,h} + rho * mu_{t,h} - y_{t,h}||_2`

over the fixed interval `[0.05,1]`. The omitted all-pairs term is mathematically constant
because the common shift cancels from every scenario difference. The chosen scalar is saved
both in `best.pt` and the resolved model configuration, reconstructed in a new model, and
checked for exact deterministic prediction equality before the one-time test call. It is
therefore neither a backpropagated neural parameter nor a test-tuned hyperparameter.

## Scope of the monotonicity statement

The hard structural statement is conditional: with the decoded graph, non-risk concepts and
market state held fixed, increasing any named downside/jump/illiquidity coordinate cannot
decrease `sigma_minus`. Risk coordinates are numerically removed—not merely detached—from
the unconstrained scale heads, and enter only through positive bounded weights. An
intervention on the initial state can also change the future graph and other concepts, so its
full closed-loop response is logged separately as sensitivity evidence and is not mislabeled
as the conditional theorem.
